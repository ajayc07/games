# core/levels

Universe-agnostic level engine: format + validation (`format.ts`), grid logic (`grid.ts`), shared physics tuning
(`physics.ts`), walking (`walk.ts`), the generic `LevelScene`, `Player` (also the demo ghost), character poses
(`characterLook.ts`, `poses.ts`), the "watch me" demo (`demo.ts`, `demoFx.ts`), level order (`progression.ts`), themes, placeholder textures, parallax
background and result screen.
See docs/ARCHITECTURE.md, "Levels".
